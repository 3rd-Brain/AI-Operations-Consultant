# FDE App: scope

Load the FDE App `consult` skill now, as a skill, and follow it in full; it is the method. Only where skills cannot be loaded by name, read its file instead, `../consult/SKILL.md` in the folder beside this one, from the first line to the last (in Codex, in ranges of at most 250 lines). This skill only sets where to start: if the request turns out to belong elsewhere, carry on with it under the method.

## Focus

From an approved Project to a build someone else can do, and proof that it worked. Follow the later steps of the Planning chain:

- Draft the Technical Scope, and the skill package when it is an agent Scope.
- Write the eval plan when the build has AI in it, and the release gate when it replaces something.
- Plan the rollout and training.
- Keep the checks three and six months after go-live as follow-ups.

Never build what a Scope specifies. If there is no approved Project yet, say so and plan it first.
